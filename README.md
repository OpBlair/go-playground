# Go Playground 

Welcome to my personal **Go (Golang) Playground**. This repository documents my journey learning Go through practical exercises, small projects, and experiments. As I continue learning, new modules covering backend development, concurrency, databases, and distributed systems will be added.

## Repository Structure

* **[go-exercises/](./go-exercises/)** — Core Go syntax, control flow, functions, structs, interfaces, and problem-solving exercises.
* *More modules coming soon...*

## Goals

* Learn Go fundamentals through hands-on practice.
* Write clean and idiomatic Go code.
* Explore backend development using Go's standard library.
* Build confidence with concurrency, databases, and system design.
* Create a collection of projects that demonstrate my learning progress.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/opblair/go-playground.git
cd go-playground
```
